# Research Papers Categorized by Relevance

## 1. Good

### 1.1 NLOS Identification and Mitigation for Localization Based on UWB Experimental Data
- **Purpose:** Keeps tag distances accurate when a machine, rock, or body blocks the signal.
- **Relevant features:** 1, 3.

### 1.2 Application of Radio-Frequency Identification Systems to Collision Avoidance in Metal/Nonmetal Mines
- **Purpose:** Tested a worker-worn tag and a machine-mounted reader in mines.
- **Specifications:** 50 ft range and 0.5 s maximum delay.
- **Relevant features:** 1, 4, 6.

### 1.3 Event-Based Sensor Data Scheduling: Trade-Off Between Communication Rate and Estimation Quality
- **Purpose:** Supports faster updates when a worker is close to a machine and reduced communication and battery usage when the worker is farther away.
- **Relevant features:** 5.

### 1.4 Robust Acoustic Positioning for Safety Applications in Underground Mining
- **Purpose:** Determines a worker's position and speed relative to a mining machine. Tested next to a real mining machine.
- **Relevant features:** 1, 4.

### 1.5 Improving Indoor Localization Using Convolutional Neural Networks on Computationally Restricted Devices
- **Purpose:** Uses machine learning for localization, designed to run on low-power hardware such as a worker-worn tag.
- **Relevant features:** 1, 3.

### 1.6 Human Detection and Activity Classification Based on Micro-Doppler Signatures Using Deep Convolutional Neural Networks
- **Purpose:** Uses radar to detect humans with 97.6% accuracy and operates in dust and darkness.
- **Additional relevance:** Addresses the limitation identified in the radar-based dump-truck paper, where radar alone cannot reliably identify what it detects.
- **Relevant features:** 2, 3.

## 2. Decent

### 2.1 Recommendations for Evaluating & Implementing Proximity Warning Systems on Surface Mining Equipment
- **Purpose:** Provides NIOSH testing procedures for mining proximity warning systems.
- **Application:** Can be used to plan the SCCL pilot.

### 2.2 Evaluation of a Radar-Based Proximity Warning System for Off-Highway Dump Trucks
- **Purpose:** Evaluates a radar-based proximity warning system on real dump trucks.
- **Results:** No missed detections, 18% false alarms, and 42% nuisance alarms.
- **Additional relevance:** Demonstrates the need for Feature 2.

### 2.3 Application of Ultra-Wide Band Sensors in Mining
- **Purpose:** Evaluates UWB tags tested in a real mine.
- **Additional relevance:** Suggests connecting tags to an emergency machine shutdown system, which is the closest any paper comes to Feature 7.

## 3. Just in Case

### 3.1 Method for Testing Proximity Detection and Alert Technology for Safe Construction Equipment Operation
- **Purpose:** Provides a method for testing proximity detection and alert technology for construction equipment safety.

### 3.2 Opportunities for Sensing Systems in Mining
- **Purpose:** Provides an overview of sensing systems and their applications in mining.

### 3.3 Seeing Through Fog Without Seeing Fog: Deep Multimodal Sensor Fusion in Unseen Adverse Weather
- **Purpose:** Supports the idea of relying on whichever sensor is not blinded by adverse conditions.
- **Limitation:** The sensors used are too expensive for the intended device.

### 3.4 Real-Time People Tracking and Identification From Sparse mm-Wave Radar Point-Clouds
- **Purpose:** Uses low-cost radar to track untagged people on a small computer.
- **Limitation:** Tested indoors only.

### 3.5 Underground Mine Positioning: A Review
- **Purpose:** Reviews underground mine positioning techniques.
